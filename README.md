# AI Story Generator

Generate short stories using GPT-2 text-generation pipeline

## Features
- Space story generation
- Horror story generation
- Motivational paragraph generation
- Adjustable parameters (max_length, temperature, num_return_sequences)
- Input validation and error handling

## Technology Stack
- Model: GPT-2 (HuggingFace Transformers)
- Pipeline: text-generation
- UI: Gradio 4.x

## Parameters Demonstrated

| Parameter | Value | Effect |
|-----------|-------|--------|
| max_length | 50-300 | Controls story length |
| temperature | 0.5-1.2 | Controls creativity |
| num_return_sequences | 1-3 | Number of variations |
